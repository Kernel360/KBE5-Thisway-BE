# 취업용 포트폴리오 완료 기준 — 여섯 단계

2026-09-08. 사용자 결정: 추가 제품 기능은 보류하고 취업용 포트폴리오 증거를 우선한다. 실제 운영 준비와 별도로 판정한다. 원 팀 구현·기존 개인 기여·AI 지원 현대화의 구분을 유지한다.

| 순서 | 과제 | 취업용 완료 기준 | 운영에서 별도 필요한 것 |
| --- | --- | --- | --- |
| 1 | metrics 접근 격리 | 미인증/오류 키/사람 ADMIN 거부, 올바른 수집키만200, 실제 Prometheus up1, 미설정 fail-closed | TLS/ingress/보안그룹, secret 배포·교체 |
| 2 | 저장 완료 지연 | 접수→DB commit 경계를 명확히 정의하고 정상/적체/중복의 p95·p99 및 미측정 수 기록 | 호스트 간 clock sync, 운영 backlog/부하 |
| 3 | 장시간·반복 부하 | 환경·데이터·순서를 고정한 반복 실험, 지연·오류·자원·적체 추이 원시 자료 | 운영 용량·SLA 승인 |
| 4 | 병목과 개선 비교 | 실행계획/병목 근거, 동일 조건의 before/after. 개선 근거가 없으면 효과 없음으로 기록 | 실제 workload 대표성 |
| 5 | 경보·중앙 로그 | 격리 환경에서 발생→수신→해제, 로그 correlation 검색·retention/권한 검증 | 실제 수신자/계정/비용·운영 보존 정책 |
| 6 | CI·PR·제출본 | FE/Emulator CI, 재현 명령·검증 근거·기여 범위·학습 질문, 리뷰 가능한 commit/PR | 공개 push/merge 승인, 실제 배포 |

진행 방식: 각 단계의 실패 조건과 결과를 작업 로그에 남기고, 검증한 범위를 다음 단계 기준선으로 사용한다. 신규 제품 기능·AI·근거 없는 최대용량 주장을 추가하지 않는다. 운영 자료가 없어도 가능한 격리 검증은 진행하며 운영 완료로 바꾸어 표현하지 않는다.

## 현재 완료 상태 (로컬 포트폴리오 기준)

- 1단계 완료: 전용 endpoint 보안 chain·수집 credential·Prometheus 설정. 전체473개 및 실제 관측성 실험1개 성공. [작업 기록](work-logs/2026-09-08-metrics-access.md).
- 2~4단계: 저장 지연·3회 반복(각5분)·조회 후보 비교 검증 완료. 측정 당시 코드 `69f34cd`.
- 5단계: 로컬 경보 발생/해제·실제 HTTP 로그 검색·권한·retention 정책 검증 완료. 지속 collector/물리 삭제 관찰은 운영 후속 범위.
- 6단계: FE/Emulator CI 및 로컬 검증·commit·제출본 마련. BE 전체475개·fleet1개·관측성1개 및20패널 실제 화면 확인 완료. 기존 PR235/84/22에 반영하고 BE/FE/Emulator 원격 CI 성공 확인. Merge/배포는 별도. [기록](work-logs/2026-09-08-remote-ci-frontend-readiness.md).
- [제출 요약과 근거](portfolio-evidence-summary.md), [전체 작업 기록](work-logs/2026-09-08-portfolio-completion.md).
